Les 1

Bestanden en extensies

Een bestand is een reeks gegevens met een naam. De extensie achter de laatste punt helpt Windows bepalen om welk soort bestand het gaat en met welk programma het standaard wordt geopend.

verslag.docx
bestandsnaamextensie

Waarom bestaat een extensie?

Windows gebruikt de extensie onder andere voor het pictogram, de standaardapp en de beschikbare acties. De extensie beschrijft het verwachte formaat, maar bewijst niet wat er werkelijk in het bestand zit.

ExtensieTypeTypische toepassing
.txtPlatte tekstKladblok, configuratie of notities
.docxWord-documentOpgemaakte tekst
.pdfPortable Document FormatDocument met vaste lay-out
.jpg, .pngAfbeeldingFoto of afbeelding
.zipArchiefEen pakket met gecomprimeerde bestanden
.html, .css, .jsWebbestandenStructuur, stijl en gedrag van een webpagina
.exe, .msiUitvoerbaar / installatieProgramma starten of installeren
.bat, .cmd, .ps1ScriptOpdrachten automatisch uitvoeren
Hernoemen is niet converteren foto.jpg hernoemen naar foto.pdf verandert de afbeeldingsgegevens niet in een pdf. Je verandert alleen het etiket.

Extensies altijd tonen

  1. Open Verkenner met Windows + E.
  2. Kies Beeld → Weergeven → Bestandsnaamextensies.
  3. Controleer of bekende bestanden nu eindigen op bijvoorbeeld .pdf, .jpg of .docx.
Waarom tonen veiliger is Als extensies verborgen zijn, kan factuur.pdf.exe lijken op factuur.pdf. De echte extensie is .exe: het is dus een programma.
1A

Praktijk: ontmasker het bestand

Maak de werking van extensies zichtbaar.

  1. Druk Windows + R, typ %USERPROFILE% en druk Enter.
  2. Maak daar een map ComputerGebruik.
  3. Open Kladblok, typ Dit is gewone tekst. en bewaar als proef.txt.
  4. Maak een kopie en hernoem die naar proef.jpg.
  5. Probeer het hernoemde bestand te openen. Noteer waarom dit mislukt.
  6. Wijzig de extensie opnieuw naar .txt.
Controle: wat is precies fout aan “een .pdf is altijd een pdf”?
De extensie is slechts een naamdeel. Een programma controleert ook de interne structuur of kenmerkende bytes van het bestand. Een verkeerde of misleidende extensie garandeert het formaat niet.
Les 2

Verborgen bestanden, systeembestanden en speciale mappen

Windows kent kenmerken toe aan bestanden en mappen. Die kenmerken beïnvloeden hoe Verkenner ze toont, maar ze versleutelen of beveiligen niets.

KenmerkLetterBetekenis
Alleen-lezenRGeeft aan dat wijzigen niet de bedoeling is. Het is geen sterke beveiliging.
VerborgenHWordt standaard niet getoond in Verkenner.
SysteemSWordt door Windows als systeembestand behandeld en extra verborgen.
ArchiefAKan door back-upsoftware worden gebruikt om wijzigingen te herkennen.

Verborgen items tonen

Open Verkenner en kies Beeld → Weergeven → Verborgen items. Verborgen bestanden verschijnen lichter. Laat in Mapopties de instelling Beveiligde besturingssysteembestanden verbergen ingeschakeld.

Verborgen ≠ geheim Iedereen kan de weergave inschakelen. Gebruik toegangsrechten of versleuteling als gegevens echt afgeschermd moeten worden.

Veelvoorkomende speciale bestanden

desktop.ini

Bewaarinstellingen voor de weergave van een map.

Thumbs.db

Cache met miniatuurweergaven van afbeeldingen.

.lnk

Een snelkoppeling, niet het doelbestand zelf.

Prullenbak

Een speciale systeemmap met verwijderde bestanden per schijf.

2A

Praktijk: bestand verbergen met attrib

Je gebruikt voor het eerst een tekstcommando.

  1. Maak in %USERPROFILE%\ComputerGebruik een tekstbestand verborgen.txt.
  2. Klik in de adresbalk van Verkenner, typ cmd en druk Enter. De opdrachtprompt opent meteen in die map.
  3. Voer onderstaande opdrachten één voor één uit.
Opdrachtprompt
attrib verborgen.txt
attrib +h verborgen.txt
dir /a
attrib -h verborgen.txt

+h zet het kenmerk Hidden aan; -h zet het uit. Met dir /a zie je ook bestanden met speciale kenmerken.

Controle: mag je desktop.ini of Thumbs.db zomaar verwijderen?
Ze bevatten doorgaans geen persoonlijk document, maar Windows kan ze nodig hebben voor mapweergave of miniaturen en kan ze opnieuw maken. Laat onbekende systeem- en configuratiebestanden staan.
Les 3

Paden, gebruikersprofielen en variabelen

Een pad is het adres van een bestand of map. Windows gebruikt een stationsletter, mappen gescheiden door een backslash en eventueel een bestandsnaam.

C: schijf \ Users map \ Sam profiel \ Documents map \ taak.txt bestand
Soort padVoorbeeldBetekenis
AbsoluutC:\Users\Sam\Documents\taak.txtVolledig adres vanaf de schijf.
Relatiefoefeningen\taak.txtAdres vanaf de huidige map.
Huidige map.De map waarin je nu werkt.
Bovenliggende map..Eén niveau hoger.
Netwerkpad (UNC)\\server\gedeeld\bestand.pdfGedeelde map op een computer of server.
Spaties in een pad? Gebruik aanhalingstekens. Typ cd "%USERPROFILE%\Mijn documenten". Zonder aanhalingstekens ziet CMD elk woord mogelijk als een apart onderdeel.

Je gebruikersprofiel

Elke gebruiker heeft normaal een eigen profielmap, bijvoorbeeld C:\Users\Sam. Daarin staan persoonlijke mappen en instellingen. Windows en programma’s bewaren er ook gegevens die je niet dagelijks ziet.

Speciale Windows-mappen

Documenten, Bureaublad en Downloads zijn known folders: Windows kent hun functie, niet alleen hun zichtbare naam. Een beheerder of OneDrive kan zo’n map naar een andere locatie omleiden. Een hardgecodeerd pad zoals C:\Users\Sam\Documents is daarom niet altijd betrouwbaar.

Open via Windows + RSpeciale locatie

shell:PersonalDocumenten, ook als die map is omgeleid
shell:DownloadsDownloads
shell:DesktopBureaublad
shell:StartupOpstartmap van de huidige gebruiker
Variabele / mapTypische waardeGebruik

%LOCALAPPDATA%...\AppData\LocalLokale appdata, caches en installaties per gebruiker

Een omgevingsvariabele is een naam met een waarde die processen van Windows kunnen lezen. In CMD schrijf je bijvoorbeeld %USERPROFILE%; in PowerShell schrijf je $env:USERPROFILE.

PATH is één bijzondere omgevingsvariabele

PATH bevat een lijst met mappen. Als je notepad typt zonder volledig pad, zoekt Windows in die mappen van links naar rechts naar een uitvoerbaar bestand met die naam.

Opdrachtprompt — variabelen bekijken
echo %USERPROFILE%
echo %APPDATA%
echo %TEMP%
echo %PATH%
where notepad
set
Niet verwarren Een pad is een adres. PATH is een variabele die meerdere zoekpaden bevat. “Path variable” wordt vaak onnauwkeurig gebruikt voor beide.

Les 5

Je eerste batchbestand

Een batchbestand is een tekstbestand met opdrachten voor cmd.exe. De regels worden van boven naar beneden uitgevoerd. Zo kun je een herhaalbare werkwijze automatiseren.

Correct opslaan

  1. Open Kladblok en plak de code hieronder.
  2. Kies Bestand → Opslaan als.
  3. Kies bij bestandstype Alle bestanden en geef de naam startmap.bat.
  4. Bewaar het in %USERPROFILE%\ComputerGebruik. Controleer dat het niet startmap.bat.txt heet.
startmap.bat
@echo off
setlocal
title ComputerGebruik

set "WERKMAP=%USERPROFILE%\ComputerGebruik\MijnProject"

if not exist "%WERKMAP%" mkdir "%WERKMAP%"
echo Welkom, %USERNAME%.
echo De werkmap is: %WERKMAP%
echo Gestart op %DATE% om %TIME%>"%WERKMAP%\startlog.txt"

start "" "%WERKMAP%"
pause
RegelUitleg
@echo offVerbergt de opdrachten zelf; je ziet alleen relevante uitvoer.
setlocalHoudt variabelen lokaal binnen dit batchbestand.
set "WERKMAP=..."Maakt een variabele. De veilige aanhalingstekens worden geen deel van de waarde.
if not exist ...Voert mkdir alleen uit als de map nog niet bestaat.
%DATE%, %TIME%Lezen bestaande omgevingsvariabelen.
start "" "%WERKMAP%"Opent de map in Verkenner. Het lege paar aanhalingstekens is de venstertitel.
pauseWacht op een toets, zodat het venster niet meteen sluit.
5A

Praktijk: uitvoeren, controleren, aanpassen

Maak van de voorbeeldcode jouw script.

  1. Voer startmap.bat uit en controleer de gemaakte map en startlog.txt.
  2. Open het batchbestand via rechtermuisknop → Bewerken.
  3. Laat het ook een lege submap afbeeldingen en documenten maken.
  4. Voer het opnieuw uit. Het moet zonder fout blijven werken.
  5. Voeg minstens één commentaarregel toe met rem.

Argumenten gebruiken

Bij maakmap.bat website is website het eerste argument. In het batchbestand lees je dit als %1. Met %~1 worden eventuele omringende aanhalingstekens verwijderd.

maakmap.bat
@echo off
setlocal

if "%~1"=="" (
  echo Gebruik: maakmap.bat projectnaam
  exit /b 1
)

set "DOEL=%USERPROFILE%\ComputerGebruik\%~1"
mkdir "%DOEL%"
echo Map gemaakt: %DOEL%
5B

Uitdaging: test beide routes

Voer het script eenmaal zonder en eenmaal met argument uit.

Opdrachtprompt
maakmap.bat
maakmap.bat "Mijn website"

Leg uit waarom de eerste uitvoering stopt met foutcode 1 en waarom de tweede aanhalingstekens nodig heeft.

Een eerste test met PowerShell

PowerShell is een moderne shell en scripttaal. CMD verwerkt vooral tekstregels; PowerShell geeft vaak gestructureerde objecten door. Opdrachten hebben meestal de vorm Werkwoord-ZelfstandigNaamwoord.

DoelCMDPowerShell
MapinhouddirGet-ChildItem
Van map veranderencdSet-Location
Map makenmkdirNew-Item -ItemType Directory
Bestand lezentypeGet-Content
Zoeken/filterenfindstrWhere-Object
Omgevingsvariabele%USERPROFILE%$env:USERPROFILE
Hulpcommando /?Get-Help commando

Eerst interactief testen

Open het Startmenu, zoek PowerShell en open een normaal venster. Voer de volgende opdrachten één voor één uit.

PowerShell
$env:USERNAME
$env:USERPROFILE
Get-Location
Get-ChildItem $env:USERPROFILE
Get-Process | Sort-Object CPU -Descending | Select-Object -First 5
Get-Command notepad

De vijfde opdracht vormt een pijplijn: procesobjecten gaan naar sorteren en daarna worden de eerste vijf geselecteerd. PowerShell geeft geen losse tabeltekst door, maar objecten met eigenschappen zoals Name, Id en CPU.

Maak systeemtest.ps1

Bewaar onderstaande code met Kladblok als systeemtest.ps1 in %USERPROFILE%\ComputerGebruik.

systeemtest.ps1
$werkmap = Join-Path $env:USERPROFILE 'ComputerGebruik'
$rapport = Join-Path $werkmap 'systeemrapport.txt'

New-Item -ItemType Directory -Path $werkmap -Force | Out-Null

$regels = @(
    "SYSTEEMRAPPORT"
    "Datum: $(Get-Date -Format 'dd-MM-yyyy HH:mm')"
    "Gebruiker: $env:USERNAME"
    "Computer: $env:COMPUTERNAME"
    "Windows: $([Environment]::OSVersion.VersionString)"
    "PowerShell: $($PSVersionTable.PSVersion)"
    "Vrij op C: $([math]::Round((Get-PSDrive C).Free / 1GB, 1)) GB"
)

$regels | Set-Content -Path $rapport -Encoding utf8
Write-Host "Rapport gemaakt: $rapport" -ForegroundColor Green
Get-Content $rapport

Script uitvoeren

PowerShell
Set-Location "$env:USERPROFILE\ComputerGebruik"
.\systeemtest.ps1
Wordt het script door beleid geblokkeerd? Wijzig de execution policy niet en gebruik geen bypass. Toon de melding aan de leerkracht; op beheerde computers kan scriptuitvoering bewust beperkt zijn. De code kan dan regel voor regel interactief worden getest.
6A

Praktijk: breid het rapport uit

Pas de array $regels aan.

  1. Voeg de waarde van $env:USERPROFILE toe.
  2. Voeg de huidige map uit Get-Location toe.
  3. Voeg zelf een titelregel met je klas toe.
  4. Voer het script opnieuw uit en controleer systeemrapport.txt.
Waarom staat er $() rond sommige opdrachten?
Binnen een tekst tussen dubbele aanhalingstekens voert $(...) eerst een expressie of opdracht uit. Het resultaat wordt daarna in de tekst geplaatst. Dit heet een subexpressie.
Eindproef

Bouw de startmap voor een webapp

Je maakt nog geen app. Je toont eerst dat je de bestanden, paden en tools begrijpt waarop een ontwikkelomgeving verder bouwt.

★

Opdracht

Maak uitsluitend met CMD of PowerShell deze structuur in %USERPROFILE%\MijnEersteApp.

Gewenste structuur
MijnEersteApp
│   index.html
│   style.css
│   script.js
│   README.txt
│
└───assets

De inhoud van README.txt bevat je naam, klas, datum en het absolute pad van de projectmap. De andere drie bestanden mogen nog leeg zijn.

CMD-route

Opdrachtprompt
cd /d "%USERPROFILE%"
mkdir MijnEersteApp
cd MijnEersteApp
mkdir assets
type nul > index.html
type nul > style.css
type nul > script.js
echo Naam: jouw naam>README.txt
echo Klas: jouw klas>>README.txt
echo Datum: %DATE%>>README.txt
echo Pad: %CD%>>README.txt
tree /f

PowerShell-route

PowerShell
$project = Join-Path $env:USERPROFILE 'MijnEersteApp'
New-Item -ItemType Directory -Path "$project\assets" -Force
New-Item -ItemType File -Path "$project\index.html" -Force
New-Item -ItemType File -Path "$project\style.css" -Force
New-Item -ItemType File -Path "$project\script.js" -Force
@(
  'Naam: jouw naam'
  'Klas: jouw klas'
  "Datum: $(Get-Date -Format 'dd-MM-yyyy')"
  "Pad: $project"
) | Set-Content "$project\README.txt"
Get-ChildItem $project -Recurse

Mondelinge controle

  1. Toon dat bestandsextensies zichtbaar zijn.
  2. Leg uit welk pad absoluut is en geef een relatief pad naar assets.
  3. Leg het verschil uit tussen %USERPROFILE% en PATH.
  4. Toon verborgen items en voer dir /a of Get-ChildItem -Force uit.
  5. Leg uit waarom index.html.txt niet hetzelfde is als index.html.
Klaar voor de volgende stap Wie deze structuur kan maken, controleren en uitleggen, is klaar om de map in VS Code te openen en te leren hoe HTML, CSS en JavaScript samen een app vormen.
